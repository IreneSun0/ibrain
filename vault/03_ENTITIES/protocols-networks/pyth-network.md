# Pyth Network

## Key Facts (CONFIRMED)

- 第一方金融数据 oracle (交易公司/交易所直发价格), Jump 孵化, 2021 上线 Solana; 核心贡献方 Douro Labs (前 Jump 团队, CEO Mike Cahill)。

- 商业化: Pyth Pro (机构 1ms 全量价格) 2025-09 上线; Q1 2026 ARR run-rate $3M → 目标年末 $10M。规模口径冲突已注 (TVS $16.1B 自报 vs Messari $4.2B)。
