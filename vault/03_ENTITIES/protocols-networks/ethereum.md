# Ethereum

## Key Facts

- 最大智能合约 L1 (PoS); EVM 标准的母体 ([[erc-20]]/[[erc-721]]/[[erc-1155]]); L2 生态 (rollups) 的结算底座; [[uma]] 与多数 DeFi 原语在此。
- 与事件市场: Polymarket 的 CTF (ERC-1155) 语义源自以太坊标准, 执行在 [[polygon]]; UMA 投票在 Ethereum 主网。
