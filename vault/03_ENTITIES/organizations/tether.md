# Tether

## Key Facts (CONFIRMED)

- USDT 发行方; 流通 ~$183.5-189.8B (2026-05~08), 占稳定币总供应 ~59%。储备: BDO Italia 季度 attestation (非 audit); Q1 2026 总资产 $191.77B / 净权益 $8.23B; ~80% 美债 + ~$8B 黄金 + ~$7B BTC。
