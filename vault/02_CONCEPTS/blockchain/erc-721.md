# ERC-721 | NFT非同质化代币标准

## Executive Definition / Chinese Explanation | 定义与解释

**ERC-721 | 非同质化代币标准（NFT）** = 一个合约里的每个 token id 都是**唯一的、不可分割、不可互换**的。

一份就是一份，不能拆成半份，也不能和另一份等价交换。

## Why This Matters | 为什么重要

在事件市场的语境里，理解 ERC-721 的价值主要在于**知道为什么它不适合结果代币**：

结果代币需要"同一结果的每一份完全等价可互换"（这样才能有订单簿、才能被做市），而 721 恰恰保证每一份都独一无二。

**这是一个结构不匹配的经典案例** —— 不是 721 不好，是它的性质和需求相反。理解这一点，就理解了为什么 [[erc-1155]] 是那个正确答案（见 [[erc-standards]]）。

## How It Works | 机制怎么运转

三个标准的选型逻辑，一句话判据：

> **你的资产需要"每一份都一样"还是"每一份都不同"？**

| 需求 | 标准 |
|---|---|
| 每份都一样，一个合约一种 | [[erc-20]] |
| 每份都不同 | **ERC-721** |
| 一个合约多种，每种内部每份都一样 | [[erc-1155]] |

**结果代币落在第三行。** 若误选第二行，就无法在订单簿上聚合成交 —— 每一份都要单独定价，市场根本无法形成。

## Concrete Example | 具体例子

假设有人真的用 ERC-721 做了结果代币：

- 你买"候选人 A 当选"，拿到 token #4471。
- 我买同一个结果，拿到 token #4472。
- **这两个 token 在链上是不同的东西。**
- 做市商挂单要挂"我买 #4471"还是"我买任意一个 A-YES"？**后者需要额外的抽象层。**
- 订单簿无法直接聚合，流动性彻底碎片化。

**结论**：标准选型错误不是"效率低一点"，而是**产品在结构上无法运转**。

（现实中确实有项目用 NFT 表示头寸，但那些通常是"仓位凭证"而非"可交易份额"—— 用途不同。）

## Common Misconceptions | 常见误解

- **误解一："NFT 就是图片。"** 721 是"唯一性"的标准，图片只是最出名的用途。
- **误解二："NFT 不能用于金融。"** 可以 —— 唯一性头寸凭证（如某些 LP 仓位）就用 721。**关键看你的资产是否需要唯一性。**
- **误解三："721 比 1155 简单所以更安全。"** 复杂度和安全性无必然关系；**结构不匹配才是真正的风险来源。**

## In Practice | 实战里怎么用

判断任何链上资产该用什么标准，一个问题：

> **"我的两份资产可以互换吗？"**

- **可以** → 同质，用 20（单一品类）或 1155（多品类）。
- **不可以** → 唯一，用 721。

**对事件市场的直接推论**：结果份额必须可互换（否则订单簿无法聚合），所以必须是 1155。**看到用 721 表示可交易结果份额的设计，那是结构性错误，不是风格选择。**

## Active-Recall Questions | 主动回忆题

- Q: ERC-721 的核心性质是什么？
  A: 每个 token id 唯一、不可分割、不可互换 —— 一份就是一份。
- Q: 为什么 ERC-721 不适合做结果代币？
  A: 结果份额必须可互换才能在订单簿上聚合成交，而 721 保证每份独一无二，会让流动性彻底碎片化，市场无法形成。
- Q: 判断资产该用什么标准的一个问题是什么？
  A: '我的两份资产可以互换吗'—— 可以则用 20 或 1155，不可以则用 721。
