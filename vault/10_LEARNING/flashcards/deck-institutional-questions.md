# 闪卡 · 机构对话八问 (workbook 原文, user-direct)

**Q1** — 学习地图每阶段的四联问是哪四个?
**A1** — 钱在哪里 / 谁承担风险 / 怎么结算 / 这个阶段必须会问什么。 → [[curriculum-source-map]]

**Q2** — 见 Exchange CTO, 第一类该问什么?
**A2** — 「哪一类失败会让你们暂停市场或拒绝某个 contract?」 → [[institutional-conversation-cheatsheet]]

**Q3** — 见 Market Maker, 第一类该问什么?
**A3** — 「你在哪些 event contracts 上最不愿意做大 size, 为什么?」 (答案暴露真实风险痛点)

**Q4** — 见 Quant PM, 第一类该问什么?
**A4** — 「你现在最难统一度量的 event exposure 是什么?」 → hyp-institutional-workflow

**Q5** — 见 Fund Manager/CIO, 第一类该问什么?
**A5** — 「什么风险会阻止你扩大 prediction/event-market allocation?」

**Q6** — 见 Wallet/Distribution 方, 第一类该问什么?
**A6** — 「想把 event markets 内嵌进钱包时, 最缺哪一层可信风险信息?」 → hyp-wallet-exchange-embedding

**Q7** — Market Maker 的钱在哪里、最怕什么?
**A7** — 钱: 自有 working capital / inventory / exchange balances / credit lines。怕: adverse selection、库存、latency、venue/counterparty、hedge 失效。

**Q8** — Exchange 的钱在哪里、最怕什么?
**A8** — 钱: 客户余额、collateral、fee revenue、insurance buffers。怕: 撮合/风控宕机、hack、坏账、清算、合规、扩容。
